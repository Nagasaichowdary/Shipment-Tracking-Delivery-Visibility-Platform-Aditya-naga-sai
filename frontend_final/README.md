# Shipment Tracker Pro

**Smart Logistics. Smarter Tracking.**

A full-stack shipment tracking platform built with React + Vite (frontend) and Spring Boot (backend).

## Features

- Role-based access: Administrator, Business Client, Logistics Operator, Customer, Support Agent, Driver
- Real-time shipment tracking with OpenStreetMap integration
- OTP-based registration and password reset
- Google OAuth2 login
- Admin dashboard with user management

## Getting Started

```bash
npm install
npm run dev
```

## Available Scripts

- `npm run dev` — Start the development server
- `npm run build` — Build the production bundle
- `npm run lint` — Lint the codebase
- `npm run preview` — Preview the production build
